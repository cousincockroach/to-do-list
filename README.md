# 📋 Structured To-Do List Application

A clean, responsive, and feature-rich task management web application built entirely with vanilla JavaScript, modern CSS, and Font Awesome vector icons. Designed around first-principles DOM manipulation and robust state handling, this app features conditional temporal filtering views to help users organize, track, and prioritize their daily tasks effectively.

[Live Link 👇](https://cousincockroach.github.io/to-do-list/)

---

## ✨ Features

* **Task Management:** Create, edit, complete, and delete tasks dynamically with instant UI updates.
* **Conditional Temporal Filtering:** Switch seamlessly between filtered views (e.g., *Inbox*, *Today*, *Upcoming*, and *Completed*) to manage time efficiently.
* **Persistent State:** Automatically saves and syncs task data using browser `localStorage` so your workflow stays intact across sessions.
* **Vector Icons & Modern UI:** Enhanced with Font Awesome vector icons and styled using a clean, responsive, card-based Vanilla CSS layout.
* **Zero Dependencies:** Built entirely with native web standards—no heavy frontend frameworks or build steps required.

---

## 🛠️ Tech Stack

* **Markup:** HTML5 (Semantic elements & custom data attributes)
* **Styling:** Vanilla CSS3 (Flexbox, CSS variables, responsive design principles)
* **Logic:** JavaScript (ES6+ classes/modules, DOM manipulation, event delegation, array methods)
* **Assets:** Font Awesome (Vector icons)
